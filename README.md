# DKU Calendar Prototype

Static multi-page university calendar website for Duke Kunshan University built with HTML, CSS, and vanilla JavaScript only.

## Run locally

Open `index.html` directly in a browser. No Node.js, package manager, server, or build step is required.

## Asset replacement

The site is configured to prefer official files if you add them later. Common replacement targets are:

- `assets/dku-logo.svg`
- `assets/dku-logo.png`
- `assets/dku-logo-reversed.svg`
- `assets/hero-campus.jpg`
- `assets/dku-campus.jpg`
- `assets/about-campus.jpg`

If those files are not present, the site uses clearly marked placeholders in `assets/`.

## Data behavior

- Built-in sample events are defined in `js/storage.js`
- Admin-added events are stored in browser `localStorage`
- Login state is stored in browser `sessionStorage`
