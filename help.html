Help & FAQ

Using the DKU calendar prototype

This local, offline prototype is designed for testing calendar workflows before a production implementation.

How do I use the calendar?

Open the monthly calendar page to move between months, click any day, and review the event panel for that date. Today is highlighted automatically.

How do I filter events?

Use the Events page search field, category filter, and sort selector to narrow the list by academic, deadline, campus life, workshop, or other event types.

How do I log in during testing?

Go to the login page and use the testing credentials: username bikki, password bikki. Successful login redirects to the admin page.

How do I add events?

After logging in, open the admin page, complete the event form, and save it. New events are stored in localStorage and appear across the site immediately.

Why are some images placeholders?

If official DKU assets are not yet present, the site uses marked placeholders. You can replace them later by adding files to the listed asset paths without changing layout code.

Prototype note

This is a frontend-only testing-phase system. It does not include backend authentication, shared accounts, or synchronized multi-user event management.
